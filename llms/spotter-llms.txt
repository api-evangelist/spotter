# Spotter

> Spotter is a Los Angeles-based creator-economy company that invests in YouTube creators
> through capital and catalog licensing, connects brands with long-form YouTube creators,
> and builds Spotter Studio — an AI-assisted ideation and planning product for professional
> creators. Spotter publishes NO public developer API, SDK, webhook surface, or developer
> portal. This file is generated by API Evangelist from public sources; it is not published
> by Spotter.

## Status

- No public API: no OpenAPI, AsyncAPI, GraphQL SDL, Postman collection, MCP server or A2A agent card was found on any Spotter host (probed 2026-08-13).
- The Spotter Studio web application calls private backends (bowser/birdo/kirby/data-api under `api.spotterstudio.com`) that return HTTP 503 to anonymous callers and publish no contract.
- Spotter Studio connects to YouTube through Google OAuth (`youtube.readonly`, `yt-analytics.readonly`, `yt-analytics-monetary.readonly`) — an inbound integration with the YouTube Data/Analytics APIs, not an API Spotter exposes.
